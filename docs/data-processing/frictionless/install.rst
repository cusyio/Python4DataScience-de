Installieren
============

Frictionless lässt sich einfach installieren mit

.. code-block:: console

   uv add frictionless

… oder falls ihr die optionale Abhängigkeit :doc:`../postgresql/sqlalchemy`
mitinstallieren wollt

.. code-block:: console

   uv add 'frictionless[sql]'

Neben `SQL <https://framework.frictionlessdata.io/docs/formats/sql.html>`_ gibt es noch
viele weitere Optionen

… für Datenquellen:

* `AWS <https://framework.frictionlessdata.io/docs/schemes/aws.html>`_

… für Datenformate:

* `Excel <https://framework.frictionlessdata.io/docs/formats/excel.html>`_
* `Gsheets <https://framework.frictionlessdata.io/docs/formats/gsheets.html>`_
* `HTML <https://framework.frictionlessdata.io/docs/formats/html.html>`_
* `JSON <https://framework.frictionlessdata.io/docs/formats/json.html>`_
* `ODS <https://framework.frictionlessdata.io/docs/formats/ods.html>`_
* `pandas <https://framework.frictionlessdata.io/docs/formats/pandas.html>`_
* `Parquet <https://framework.frictionlessdata.io/docs/formats/parquet.html>`_
* `SPSS <https://framework.frictionlessdata.io/docs/formats/spss.html>`_

… für Datenportale:

* `CKAN <https://framework.frictionlessdata.io/docs/portals/ckan.html>`_
