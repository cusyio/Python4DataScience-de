Frictionless
============

Frictionless ist ein Datenmanagement-Framework für Python, das Funktionen zum
:doc:`describe`, :doc:`extract`, :doc:`validate` und :doc:`transform` tabellarischer
Daten bereitstellt. Es unterstützt eine Vielzahl von Datenquellen und -formaten und
bietet zudem Integrationen mit gängigen Plattformen. Das Framework basiert auf den
*Frictionless Standards*.

.. seealso::
    * `Frictionless Framework <https://framework.frictionlessdata.io>`_
    * `Frictionless Standards <https://specs.frictionlessdata.io>`_
