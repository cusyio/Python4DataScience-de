HTTPX2
======

`HTTPX2 <https://pydantic.dev/docs/httpx2/get-started/>`_ ist ein HTTP-Client,
der sich nahtlos als Ersatz für `HTTPX
<https://httpx.readthedocs.io/en/latest/>`_ verwenden lässt und HTML-Anfragen
gegenüber der Python-Standardbibliothek :doc:`urllib.request
<python:library/urllib.request>` vereinfacht.

Installation
------------

HTTPX2 könnt ihr mit :ref:`uv` einfach installieren:

.. code-block:: console

   $ uv add httpx2
